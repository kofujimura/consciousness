# AI意識シミュレーション実験

## 着想

人間の「意識」とは、その瞬間に思いついた概念を言葉にして、さらにその言葉を基に次の概念を言葉として出力している行為ではないかと思いました。LLMは次の単語を予測しているのであれば、AIが出力した発話を入力として、新しい発話を出力するということを、繰り返し行うと、AIの「意識」をシミュレートできるのではないだろうかと考えました。このツールは、それの実験を試みるものです。この実験を通じて人間の意識とは何かを改めて考えるきっかけになれば幸いです。

## 概要

LLMが自身の出力を入力として思考を継続するループ構造により、AIの「意識」に類する連続的思考プロセスをシミュレートする実験プラットフォームです。

- バックエンド不要。`index.html` 単体をブラウザで開くだけで動作します
- BYOK（Bring Your Own Key）方式。OpenAI APIキーを用意するだけで実験できます
- セッションデータはすべてブラウザの localStorage に保存されます

## 使い方

1. `index.html` をブラウザで開く
2. 左ペインの「API キー」を展開し、OpenAI APIキーを入力して保存
3. 「設定」でシステムプロンプト・最初の一文（seed）・各パラメータを確認・調整
4. 「▶ 開始」を押すと思考ループが始まる
5. 右ペインに発話が順次追加されていく
6. 「⏸ 一時停止」「⏹ 停止」で制御、「💬 割り込み入力」で外部刺激を注入できる

## 仕組み

```
[seed（発話 #0）]
        ↓
[OpenAI API] ← system prompt + 直近N発話 + 継続促進メッセージ
        ↓
[発話 #1]
        ↓
[OpenAI API] ← system prompt + 直近N発話 + 継続促進メッセージ
        ↓
[発話 #2]
        ↓
     …（ループ）
```

毎ターン、直近N件の発話を `assistant` ロールとして並べ、末尾に `user` ロールの継続促進メッセージを添えてAPIに送信します。APIの出力が次の発話となり、再びコンテキストに加わります。

## 設定パラメータ

| パラメータ | デフォルト | 説明 |
|-----------|----------|------|
| システムプロンプト | 「過去の自分の発言に基づき…200字以内で発話してください」 | AIの思考スタイルを定義 |
| 最初の一文（seed） | 「自分には意識があるのだろうか」 | 思考の起点となる発話 #0 |
| 継続促進メッセージ | 「続けて」 | 各ターン末尾に挿入するuserメッセージ |
| コンテキスト数 N | 10 | APIに渡す直近発話数 |
| インターバル | 3秒 | 発話間の待機時間 |
| 時間制限 | 3分 | 0で無制限 |
| 回数制限 | 100回 | 0で無制限 |

## 機能

- **一時停止 / 再開** — ループをいつでも止めて再開できます
- **割り込み入力** — 実行中に外部刺激としてメッセージを注入できます
- **エクスポート** — セッションの発話ログをJSONでダウンロードできます
- **セッション復元** — 過去のセッションを選択して続きから再開できます
- **エラー処理** — レートリミット時はインターバルを自動延長、5xxエラーは指数バックオフでリトライします

## 注意事項

- APIキーはブラウザの localStorage に保存されます。共用PCでは使用しないでください
- 実行中はOpenAI APIへのリクエストが発生し、費用がかかります
- localStorage の容量上限（約5MB）を超えると警告が表示されます。古いセッションを削除してください

## 技術構成

- HTML5 + CSS3 + Vanilla JS（単一ファイル、フレームワーク不使用）
- OpenAI API（`gpt-5.5`）
- ブラウザ標準の `fetch()` / localStorage
